This project analyzes sales data using SQL to answer common business questions and demonstrate Data Analyst skills.

### Skills Used

* SELECT
* WHERE
* ORDER BY
* Aggregate Functions (SUM, AVG, MAX)
* GROUP BY
* HAVING
* CASE Statement
